# tiny-chess-engine-v3

A chess engine in under 4 KB of Python, built for the make.fun
tiny-chess-01 competition. 0x88 mailbox board, negamax alpha-beta with
iterative deepening, transposition table, null-move pruning, quiescence
search with check evasions, MVV-LVA ordering and piece-square tables.
Deterministic fixed node budget, standard library only.
